# IIM Amritsar Website

A professional, modern minimalist web application representing the **Indian Institute of Management (IIM) Amritsar**. Built with React 18, Vite, TypeScript, and Tailwind CSS.

## Features Included

- **Navbar**: Responsive navigation with smooth scrolling links and mobile menu toggle.
- **Hero Section**: Prestigious academic messaging, high-impact statistics (CTC, Recruiters, Diversity), and quick CTAs.
- **About Section**: Comprehensive institute overview, mission, vision, and campus infrastructure highlights.
- **Programs Section**: Interactive tabbed view covering MBA, MBA in Business Analytics, Ph.D., and Executive programs with eligibility and highlights.
- **Admissions Section**: Step-by-step CAT & shortlisting process guide with enquiry support.
- **Placements Section**: Key metrics including highest CTC (₹ 58.52 LPA), average CTC, and prominent recruiter logos (Amazon, Deloitte, EY, ICICI, etc.).
- **Contact Section**: Detailed campus address, contact details, and an interactive enquiry submission form with success state.
- **Footer**: Quick links, accreditation details, and quick return-to-top functionality.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16+) installed.

### Installation

1. Clone or download this project.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser at `http://localhost:3000`.

### Build for Production
```bash
npm run build
```
